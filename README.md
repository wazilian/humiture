# humiture
ESP32 project utilizing the DHT22 temperature and humidity sensor. Sensor data can be accessed via an embedded webpage and soon to be accessed in a centralized location with data shipped via HTTP or MQTT to see environmental trends.

## Current Hardware
* ESP32-WROOM-32D
* DHT22 temperature and humidity sensor
* Anode LED
* (Future) Data shipment via HTTP and/or MQTT to cloud or local server housing RDMS
* (Future) I might add a CO2 sensor
* (Future) stylish small enclosure box of one's choosing
